Peg Mechanics & Mathematics

Fixed Mathematical Ratio:
1 e-AED = 22.5 e-INR

The CrossBorderCBDCSwap contract enforces deterministic cross-currency parity backed by bilateral sovereign currency corridors. By locking standard conversion ratios within decentralized state machines, financial institutions eradicate the 3% to 7% foreign exchange friction typical of conventional correspondent banking.

INR to AED Conversion Formula

aedAmount = (inrAmount * 1e18) / (22.5 * 1e18)

For example: 22,500 e-INR ÷ 22.5 = exactly 1,000.00 e-AED.

AED to INR Conversion Formula

inrAmount = (aedAmount * 225) / 10

For example: 1,000 e-AED × 22.5 = exactly 22,500.00 e-INR.

CrossBorderCBDCSwap.sol • transferInrToAed 

pragma solidity ^0.8.20;

/**
 * @title CrossBorderCBDCSwap
 * @notice Bilateral Atomic Swap for Indian e-INR and UAE e-AED
 * @dev Enforces 1 e-AED = 22.5 e-INR fixed ratio
 */
contract CrossBorderCBDCSwap {
    address public immutable bankIndia;
    address public immutable bankUAE;
    
    IERC20 public immutable eINR;
    IERC20 public immutable eAED;
    
    // 1 e-AED = 22.5 e-INR (Scaled by 1e18)
    uint256 public constant INR_PER_AED_RATIO = 22.5 * 1e18;

    event SwapInrToAed(address indexed sender, address indexed recipient, uint256 inrAmount, uint256 aedAmount);

    /**
     * @notice Converts e-INR directly to e-AED
     * @param inrAmount Amount of e-INR to deposit (18 decimals)
     * @param recipientAed Recipient CBDC address in UAE
     */
    function transferInrToAed(
        uint256 inrAmount, 
        address recipientAed
    ) external returns (uint256 aedAmount) {
        require(inrAmount > 0, "Invalid INR amount");
        require(recipientAed != address(0), "Invalid recipient");

        // Calculate proportional e-AED output
        aedAmount = (inrAmount * 1e18) / INR_PER_AED_RATIO;
        require(eAED.balanceOf(address(this)) >= aedAmount, "Insufficient e-AED liquidity");

        // Atomic settlement: Collect e-INR -> Payout e-AED
        eINR.transferFrom(msg.sender, address(this), inrAmount);
        eAED.transfer(recipientAed, aedAmount);

        emit SwapInrToAed(msg.sender, recipientAed, inrAmount, aedAmount);
        return aedAmount;
    }
}

CrossBorderCBDCSwap Clarifications

The 1:22.5 exchange rate is set pursuant to the bilateral local currency settlement bilateral framework established between the RBI and CBUAE. It represents the target benchmark exchange mechanism embedded in the smart contract's state machine, shielded from speculative decentralized exchange volatility.

The smart contract conforms to EVM ERC-20 token interface specifications; however, only addresses that have cleared CBDC participant KYC and possess verified soulbound credentials recognized by either `bankIndia` or `bankUAE` can successfully broadcast swap transactions.
